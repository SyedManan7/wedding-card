# Luxury 3D Wedding Invitation Card — Bazm-e-Ghulab

An elegant, mobile-responsive interactive 3D digital wedding invitation card.

### 🌟 Key Features
- **Interactive 3D Folding Envelope** with golden wax seal
- **Autoplay Ambient Celebration Music** with custom playback controls
- **Full-Screen Confetti Blast**
- **Scratch-to-Reveal Countdown**
- **Event Timeline Cards** (Dholki, Mehndi, Nikkah, Baraat, Walima)
- **Add to Google Calendar Integration**
- **Interactive Photo Gallery & RSVP**
- **Bilingual Support (English & Urdu)**
